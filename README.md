# LogiFlow - Gerenciador Logístico

## Sobre o projeto
O LogiFlow é um sistema web de gerenciamento logístico desenvolvido para a Atividade Prática Orientada (APO) da disciplina de Fundamentos de Programação para Internet da UNIPAR.

O sistema tem como objetivo facilitar o cadastro e a organização de produtos, endereços, transportadores e operações de frete.

## Funcionalidades
- Cadastro, edição e exclusão de produtos.
- Gerenciamento de endereços.
- Cadastro de transportadores.
- Geração de fretes com seleção de produtos, origem e destino.
- Consulta de fretes registrados.
- Exportação de relatórios em formato CSV.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Como executar
1. Instalar o XAMPP.
2. Colocar a pasta do projeto dentro de htdocs.
3. Iniciar Apache e MySQL no XAMPP.
4. Configurar o banco de dados MySQL.
5. Acessar http://localhost/gerenciador_fretes/ no navegador.

## Finalidade
Projeto acadêmico desenvolvido para demonstrar conhecimentos de programação para internet e gerenciamento de informações logísticas.
